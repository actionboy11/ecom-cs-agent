# 关键词分类规则只做降级兜底，且冻结、不参与质量评测

## Status

accepted

## Context

没有模型 Key 或模型超时时，意图分类需要一条兜底路径，因此实现了基于关键词和正则的 `_keyword_classify`。在 60 条自建用例上，随着规则不断补充，其准确率从 82% 升到 100%。

## Decision

关键词规则**冻结**：不再为提升评测分数而修改；它只用于模型不可用时的降级，并且**不计入质量指标**。质量指标只衡量 LLM 链路。

## Considered Options

- 继续调规则直到 100%：会把评测变成"自己出题自己考"，规则越拟合用例，越无法反映真实能力。
- 删掉规则：则本地无 Key 时无法运行，开发体验变差。

## Consequences

- 评测报告里必须标注"本次走的是 LLM 链路还是关键词兜底"，否则数字无意义。
- 新意图（如 product_info）仍需补少量关键词，但只保证"能跑通"，不追求分数。
- 引入 train / holdout 划分（48 / 12），规则改动只能看 train，holdout 用于验收。
