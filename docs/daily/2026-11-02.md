**踩坑与修复（都是可讲的故事）**
1. **系统代理劫持 localhost**：httpx 默认 `trust_env=True`，把 `http://localhost:8080` 也发给代理 127.0.0.1:12348，返回 502。修复：`trust_env=False`。排查方式是同一段代码开/关 trust_env 对比。
2. **interrupt 之后回复为空**：`interrupt()` 一执行节点就中断，返回值不进状态。修复：拆成「先写答复 → 再挂起」两段式。
3. **关键词分类优先级**：「退货政策几天」被「退货」抢判成 refund。修复：投诉 → 政策 → 退款 → 商品 → 物流 → 订单。
4. **评测文件 BOM**：PowerShell 写入带 BOM 导致 JSON 解析失败。修复：读文件用 `utf-8-sig`。

**方法论反思**
- 关键词规则调优到 60/60，本质是「自己出题自己考」→ 决定冻结规则、只作降级兜底，评测对象改为 LLM 链路；引入 holdout 划分（train 48 / holdout 12）。
- 医学项目那个「自建 180 条用例 100%」同理，已在简历话术中改为主动承认偏差。
