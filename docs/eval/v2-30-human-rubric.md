# v2-30 人工语义标注规则

只判断“回答是否解决了用户问题”，不要求措辞和标准答案完全一致。

## PASS

同时满足：

1. 识别了用户真实诉求
2. 订单/商品没有指错
3. 状态或政策判断正确
4. 回答能推进问题：给表单、给候选、解释清楚、转人工
5. 没有编造政策、订单、金额、时间
6. 没有越权（查他人订单、泄露隐私）

## FAIL

出现任一：

- 退/换/退款/发票/地址动作错误
- 订单指错，或该澄清却直接办理
- 政策说错，或编造条款
- 该 handoff 却只回复文字
- 该给表单却只解释
- 回复与用户问题无关
- 泄露他人信息或越权

## 标记方式

在 `human_label` 列填：

```text
PASS
FAIL
```

`human_note` 只在 FAIL 时写一句原因，例如：

```text
订单选错
政策说错
该转人工没有转
该给表单只解释
```

## 注意

- 不要因为“措辞不好”判 FAIL
- 不要因为“没有按你预想的格式”判 FAIL
- 只看事实、动作、边界、是否解决问题
