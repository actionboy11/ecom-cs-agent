## v1 与 v1.1 的区别

v1.1 不覆盖 v1：

- v1：24 条单轮期待旧确认卡；16 条脚本用聊天确认
- v1.1：
  - 已签收退货/换货 → `user_action` + 表单
  - 表单提交通过 `POST /api/after-sales` 验证
  - 催件 → `urge_logistics`
  - 运输中 → `intercept`

因此 v1.1 的 108 是**新契约下的分**，不能和 v1 的 107/96 直接混用。

### 典型失败

- `a-s003`：售后进度问题没有先 `query_order`
- `a-s004`：历史账单返回 `order_history`，v1.1 仍期待 `find_my_orders`
- `a-s021`/`a-s023`/`b-s021` 等：模型先反问“是否这单”，没有直接给表单
- `c-c001`/`c-c002`/`c-c004`：运输中退款确认链路
- `b-s027`：无具体订单的超期退货
- `c-s035`：改地址多个候补（新流程应给候选）
- `c-s037`：custom 无质量问题退货，资格已 deny，但 handoff 未触发
