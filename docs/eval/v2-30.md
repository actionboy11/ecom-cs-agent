## 这轮修了什么

### PendingCase

首轮多候选时保存：

```text
action（可为空）
original_text
candidates
```

次轮选择订单后：

```text
恢复 PendingCase
→ action 已知：出表单
→ action 未知：问“退货 / 换货 / 维修”
→ 用户回答后再出表单
```

不再要求用户第一轮必须说“退/换”，也不再用“充不进/晃/拧不上”这类症状词强行猜退货。

### 政策层

- 价保 / 以旧换新 / 客服电话：`answer`
- 赔偿 / 物品损失 / 明确转人工：`handoff`
- 退款差额：先查售后，无明细再 handoff
